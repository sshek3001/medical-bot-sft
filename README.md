## Customer Service Model to book appointment for a Hospital

### The properties of the agent
- Agent should have distinctive medical knowledge
- The agent should be able to take calls, listen to the customer's grievances.
- From the conversation the agent should be able to determine the correct department and available doctor that should be able to treat the patient.
- The agent should have comprehensive scheduling knowledge to book into the correct slot.
